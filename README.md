# 쿠팡 상품 분석기

쿠팡에서 키워드를 검색한 화면을 **버튼 한 번으로 수집**해서
가격대·리뷰·경쟁 강도를 분석하고, **구글시트에 저장·추적**하는 크롬 확장 프로그램입니다.
상품 상세 페이지의 리뷰를 모아 **AI가 "왜 잘 팔리는지 / 어떻게 차별화할지"** 정리해 줍니다.

> ⚠️ 쿠팡은 실제 판매량을 공개하지 않습니다. 이 프로그램의 판매량·매출은 모두 **리뷰 수 기반 추정치**입니다.
> 사람이 직접 보는 화면만 읽는 방식이라 자동 크롤링보다 차단 위험이 낮지만, 쿠팡 약관상 대량 자동 수집은 제한되니 필요한 만큼만 사용하세요.

## 할 수 있는 것

| 기능 | 설명 |
|---|---|
| 검색 결과 수집 | 상품명, 가격, 리뷰 수, 별점, 로켓 여부, 광고 여부, 순위 |
| 키워드 분석 | 평균·중간 가격, 가격 범위, 상위10 평균 리뷰, 상위3 독점률, 로켓 비율, **진입 난이도** |
| 가격대별 판매 비중 | 어느 가격대가 가장 많이 팔리는지 (리뷰 합 기준) |
| 추천 메시지 | 독점 시장인지, 뜨는 신상품이 있는지, 로켓 입점이 필요한지 |
| 구글시트 저장 | `수집기록` · `키워드요약` · `판매추적` · `리뷰분석` 탭 자동 생성 |
| 판매 추적 | 같은 키워드를 **다른 날 다시 수집**하면 리뷰 증가량으로 하루 판매·월매출 추정 |
| AI 리뷰 분석 | 잘 팔리는 이유, 장점, 불만, 차별화 아이디어, 상세페이지 문구 (OpenAI API) |
| CSV 저장 | 엑셀로 바로 열기 |

## 설치 1 — 크롬 확장 프로그램

1. 이 저장소에서 **Code → Download ZIP** 으로 내려받아 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` 입력
3. 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** → 압축 푼 폴더 안의 `extension` 폴더 선택
5. 크롬 오른쪽 위 퍼즐 아이콘 → **쿠팡 상품 분석기** 고정(📌)

이것만 해도 검색 분석과 CSV 저장은 바로 쓸 수 있습니다.

## 설치 2 — 구글시트 연결 (저장·추적·AI 분석용)

1. 새 구글시트를 만들고 이름을 `쿠팡 상품 분석`으로 정합니다.
2. 메뉴 **확장 프로그램 → Apps Script**
3. 기본 코드를 지우고 `apps-script/Code.gs` 내용을 붙여넣고 저장
4. 위쪽 함수 선택에서 `setup` 선택 → **실행** → 권한 승인 (탭 4개가 생깁니다)
5. (AI 분석을 쓸 때) 왼쪽 ⚙️ **프로젝트 설정 → 스크립트 속성 추가**
   - `OPENAI_API_KEY` = 본인 OpenAI 키
   - (선택) `OPENAI_MODEL` = `gpt-4o-mini` (기본값)
6. 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 → 나오는 **웹 앱 URL** 복사 (`https://script.google.com/macros/s/…/exec`)
7. 확장 프로그램 → **설정** 탭 → URL 붙여넣기 → **저장** → **연결 테스트**

> 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 반영됩니다.

## 사용 방법

### 검색 분석
1. 쿠팡에서 키워드 검색 (예: `차조`)
2. 페이지를 끝까지 스크롤 (상품이 다 보이도록)
3. 확장 아이콘 → **이 페이지 수집**
4. 2~3페이지로 넘기며 반복하면 데이터가 쌓입니다
5. **구글시트로 보내기**

### 판매 추적 (진짜 판매 흐름 보기)
- 관심 키워드를 **매일 1번** 같은 방식으로 수집해서 시트로 보내세요.
- `판매추적` 탭에서 상품별 **하루 리뷰 증가 → 추정 하루 판매 → 추정 월매출**이 계산됩니다.
- 1일 이상 지나야 계산됩니다.

### 리뷰 AI 분석
1. 분석할 상품의 상세 페이지 열기
2. 아래 **상품평** 영역까지 스크롤해서 리뷰가 보이게 하기
3. 확장 아이콘 → **리뷰 분석** 탭 → **리뷰 수집**
4. 리뷰 페이지(2, 3, 4…)를 넘기며 반복 (별점 낮은 순 정렬도 한 번 수집하면 불만이 잘 잡힘)
5. **AI로 분석** → 결과가 화면과 `리뷰분석` 탭에 저장됩니다

## 추정 방식

- **누적 판매 추정** = 리뷰 수 × 배수 (기본 30, 설정에서 변경)
  - 리뷰는 보통 구매 20~100건당 1개꼴로 달립니다. 저가 생필품은 배수를 높게, 고가품은 낮게 잡으세요.
- **하루 판매 추정** = (최근 리뷰 수 − 첫 수집 리뷰 수) ÷ 경과일 × 배수
- **진입 난이도** (광고 제외 상위 10개 평균 리뷰 기준): 300 미만 쉬움 / 2,000 미만 보통 / 10,000 미만 어려움 / 그 이상 매우 어려움

## 쿠팡 화면이 바뀌어 수집이 안 될 때

쿠팡은 화면 구조를 자주 바꿉니다. 이 프로그램은 클래스 이름 대신 "상품 링크 + 원/괄호 숫자 패턴"으로 읽도록 만들어 웬만한 변경에는 버티지만,
그래도 안 되면 `extension/content.js`의 `extractPrice` / `extractReviewCount` 부분을 수정하면 됩니다.
수정 후 `npm test`로 샘플 화면 테스트를 돌려 보세요.

## 폴더 구조

```
extension/        크롬 확장 프로그램
  manifest.json
  content.js      쿠팡 화면 읽기
  analysis.js     분석 계산
  popup.html/css/js  화면
apps-script/
  Code.gs         구글시트 저장·추적·AI 분석
test/test.js      수집·분석 테스트 (npm test)
```
